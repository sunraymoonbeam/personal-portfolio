## Why I built it

Kanta is a collaborative camera app for events. The idea was to make it easier for people to put their photos in one place and find the ones they care about. I wanted sharing to work more like a common photo library than a set of separate chats and albums.

## The backend

I built the backend with FastAPI. Images live in Azure Blob Storage, and Azure PostgreSQL stores the data we need to query them. The application runs on Azure Container Apps. I used an AWS Lambda job for unsupervised clustering to help organise the photo collection.

<Figure src={storage} alt="FastAPI on Azure Container Apps connects to Blob Storage for image files and PostgreSQL for queryable photo data." caption="The storage split in Kanta's backend. An architecture summary, not a product screenshot." />

Kanta also uses face detection to make a large set of event photos easier to navigate.

## What I took from it

Building a photo app forced me to think about both sides of a file upload: where the image bytes live and how a person finds the right image afterwards. The storage and query model had to support the experience together.

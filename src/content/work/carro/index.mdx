## Working from the actual need

At Carro I work with stakeholders to understand which customer service tasks and internal processes an agent can help with. The work has grown into twelve production agent workflows across Singapore, Malaysia and Hong Kong. Together they service more than 60,000 tickets a month.

That scale changes what matters. A workflow has to retrieve the right information, be observable when it fails and cost a sensible amount to run. I also build harnesses for internal data retrieval, reporting and operational tasks across departments.

## The infrastructure underneath

I built core AI infrastructure on Google Cloud. LiteLLM routes model calls, and Langfuse gives us tracing and evaluation. Those tools help us see what each workflow is doing and make changes based on evidence.

I reduced LLM costs by 80% through harness optimisation and more deliberate model routing. I also developed n8n automations for customer outreach, contributing to 30% revenue growth in Singapore's workshops.

## How I approach this work

I start with the business process, then work back to the data and the smallest useful automation. I want to know what success looks like to the people using it, and how we will notice when it stops working. The model is only one part of that system.

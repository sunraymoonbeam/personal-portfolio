Twelve agents, 60k tickets a month, and an 80% smaller LLM bill

I joined to build one support agent. It turned into a platform.

ZL
Zack LowSingapore · 6 min read
Owned
Agents, LLM platform, automations
Stack
LangGraph, LiteLLM, Langfuse, n8n
Team
Me, one PM, six ops leads

The setup

Carro sells and services cars across four countries, and support runs through tickets. About 60,000 a month. Six ops leads were reading them by hand, sorting them, and pasting the same twelve replies. Everyone knew an agent could take a chunk of it. Nobody had time to build one, so they hired me.

The wrong turn

I built the first agent in three weeks, straight against the model API, and it worked in the demo. Then it went live and I could not see anything. Which tickets it touched, what it cost, why it replied in Malay to a refund request nobody wrote in Malay. I spent the next two weeks not on the agent, but on being able to see the agent.

What I actually did

  • Put LiteLLM in front of every model call, so swapping providers is a config change.
  • Sent every call to Langfuse. Cost per ticket, per agent, per model, with the full trace.
  • Rebuilt the agents in LangGraph as twelve small workflows instead of one big one.
  • Ran a cost trial per agent and moved most to cheaper models where the evals held.
  • Wired n8n into sales and ops for the parts that never needed a model.

What changed

Twelve agents handle about 60,000 tickets a month. The LLM bill dropped by roughly 80% after the cost trials, mostly by not using a frontier model to sort tickets. The n8n automations are tied to about 30% revenue growth on the sales side. The ops leads stopped pasting.

Sidenote

The Malay reply was a language-detection prompt firing on a customer's surname. Nobody asked it to. That one ticket is why every agent now has an eval set before it gets a model swap.

What I'd do differently

Build the tracing first, before the first agent. And write the eval set with the ops leads on day one, not after the Malay incident. Both would have saved about a month.
